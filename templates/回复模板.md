# 回复模板（博主回信之后）

> 看板「待你回复」里的回信由这份模板拼出来，AI 只写开头一两句、回答对方问到的具体问题。改这里的措辞，看板里所有回信跟着变（每次起草都重新读这个文件，不用重启）。
> 现在是一个虚构的居家健身 App「Acme Fit」的版本，当例子用：安装时按你的产品、条件和语气改写（见 SETUP.md 第 7 步）。
> - 回信按情况分：出价（对方报过价就是还价，没报过就是直接出价）、接受报价、请他先报价、婉拒；对方明确拒绝的回个谢。
> - 每封信都能在「段落 / 要点 / 简短」三种样子之间切换。
> - 附加条件的开关（投流、分成、Pro、排他、标注）在 config.json 的 addons 里定按钮文字和默认开关；措辞在下面同名的小节。
> - 价格、条数、平台、币种在看板回复框上面填，信里的价格那句跟着变。

占位符（看板自动换掉）：

| 占位符 | 换成什么 |
|---|---|
| `{称呼}` | 信开头称呼的人：博主本人，或代回的经纪人 |
| `{发件人}` | 发件人的名字（config.json 里的 sender.name），用在署名 |
| `{价格}` | 你在回复框填的价格，按对方币种写，日韩台加含税说明 |
| `{内容}` | 条数加平台，例如 one TikTok、兩支 TikTok 影片 |
| `{your}` `{You}` `{you}` `{you're}` `{you'd}` `{them}` `{write}` | 英文人称。对博主本人是 your / You / you / you're / you'd / you / write；对经纪人换成博主名字（Cleo's / Cleo / Cleo is / Cleo would / them / writes） |
| `{the video}` `{The video}` `{it}` `{script}` `{the post}` | 英文单复数：一条是 the video / it / script / the post，多条是 each video / each one / scripts / each post |
| `{每支}` `{각}` `{各}` | 繁中、韩文、日文的「每条」，一条时为空 |
| `{으로}` `{을}` | 韩文助词，按价格最后一个字自动选 |
| `{你}` `{你的}` `{视频}` | 中文意思里的人称和单复数 |

每个小节第一个代码块是正文，第二个是中文意思（看板「中文意思」里显示；繁中正文本身就是中文，不需要）。
