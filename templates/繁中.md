# 繁中模板（CHATKOL）

> 看板用到这里的三段：「跟进一」「跟进二」是自动跟进发的信，「私信 · 通用版」是「私信待发」清单里复制用的模板。「首封」看板不用，给你在 EasyKOL 或邮箱里发第一封时参考。名字写成 `{暱稱}`，看板会换成对方的名字。每段第一个代码块是正文。现在是一个虚构的居家健身 App「Acme Fit」的版本，当例子用，安装时按你的产品改写。
## 首封

```
{暱稱} 你好！

我是 Acme Fit 的合作負責人 Alex。Acme Fit 是一款居家健身 App，會依照你的時間和手邊的器材，排出 20 分鐘的訓練計畫。

很喜歡你分享運動的方式，簡單又好跟，所以想邀請你合作一支付費短影音，希望它就像你平常的內容：題材和腳本都由你發想，我們只會在拍攝前確認產品資訊正確。

我們大致的想法是：
• 一支 60 秒以內的短影音，發在你的主帳號
• 接下來兩週內發布，時間由你安排
• 送你一年的 Acme Fit 會員

如果有興趣，方便提供一支影片的合作報價嗎？完全沒有壓力，謝謝你花時間看完！

Alex
Acme Fit 合作負責人
```

## 跟进一

```
{暱稱} 你好！

怕上一封信被其他信件淹沒了，再來跟你打聲招呼～最近一定很忙吧！

很想跟你合作一支發在主帳號的付費影片，題材和腳本都由你決定，我們只在拍攝前確認一次產品資訊。

有興趣的話，方便告訴我一支影片的報價嗎？現在不方便也完全沒關係，謝謝你！

{发件人}
```

## 跟进二

```
{暱稱} 你好！

不想一直打擾你，這是我最後一次來信囉。

之後如果付費合作剛好適合，回我一支影片的報價就好，我來接著安排。一直很喜歡你分享的內容，繼續加油！

{发件人}
```
